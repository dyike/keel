# 动效示例

[English](README.md) | 简体中文

原独立动效程序已合并到 [Components](../components/README.zh-CN.md)，统一示例入口，每种演示只维护一份实现。

    go run ./examples/components -lang zh-CN
    go run ./examples/components -section motion_effects -lang zh-CN
    go run ./examples/components -section motion_timeline -lang zh-CN

侧栏的“动效”分类包含数值/缓动/关键帧、手势、进退场/布局、滚动联动、弹簧预设、页面切换、姿态、时间线、指针光晕/波纹、彩纸、RisingGlow 和 ShimmerText。
