# Motion examples

English | [简体中文](README.zh-CN.md)

The standalone motion executable has been merged into [Components](../components/README.md). There is one gallery and one implementation for each demonstration.

    go run ./examples/components
    go run ./examples/components -section motion_effects
    go run ./examples/components -section motion_timeline

Choose Motion in the sidebar for values/easing/keyframes, gestures, presence/layout, scroll linking, spring presets, page transitions, poses, timelines, cursor glow/ripples, confetti, RisingGlow and ShimmerText.
