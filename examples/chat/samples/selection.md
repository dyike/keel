## 跨段落选择

从这一段的中间开始拖动，越过下一段、列表和代码，再拖到表格里。反向拖动也应得到相同的文字。

第二段包含 **加粗文字**、*斜体文字*、`inline code` 和 [Go 文档](https://go.dev/doc/)。从链接开始拖选时不应打开网页；单击链接应打开网页。

> 引用中的文字也应包含在跨块选区里。

1. 列表第一项，带有 `context.Context`。
2. 列表第二项，包含 **粗体片段**。

```go
func greet(name string) string {
    return "你好，" + name
}
```

| 名称 | 数值 | 说明 |
|:--|--:|:--:|
| 甲乙 | 12 | 第一行 |
| 丙丁 | 34 | 第二行 |

选中这篇回答后按 Cmd/Ctrl+A，再按 Cmd/Ctrl+C，粘贴检查整篇纯文本。表格列之间应是制表符，行之间应换行，列表标记和代码复制按钮不应进入选区。

流式输出时可以往上滚动后选择已经到达的文字；继续输出和回答结束时，已有选区应保留。
