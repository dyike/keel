# Keel 文档

第一次使用，从“快速开始”运行第一个窗口。开发应用时查“编写应用”和“组件参考”；修改框架时再看“参与开发”。

- [主题](theme.md)：配色、字体、尺寸、局部主题与动态效果。
- [Markdown](markdown.md)：流式输出、代码块、缓存和定制。
