This is a competency comparison and does not require duplication of the Rust API.

Status after completion: **73 items have existing entities, 4 items are partially covered, and 0 items have different purposes** (first review is 38/36/3). This is judged by documented features, not feature completion percentage, nor a visual maturity score.

- **Subject already exists**: core purposes covered; differences in configuration, interaction or combination methods are still listed in the last column and cannot be read as all functions are the same.
- **Part**: There is an operable main body, but it lacks the extended functions or combination capabilities explicitly provided by the source site; the implemented part will continue to be recorded as completed.
- **Different uses**: The old table replaces components with different uses with the same name or similar effects, and the corresponding relationship needs to be re-established.

This round is a static review of documents and source code, and checks the cross-file extension interface; there is no re-run of 77 real-machine interactions, nor is there any proof of visual consistency one by one. The gap refers to the interface/behavior that is not currently provided by the component. The application's own combination through `el` is not automatically counted as the kit has been packaged. GPUI documentation examples are not equivalent to the upstream source code and are verified for all platforms.

## This round of corrections and key gaps

1. The first review corrected the confusion of the uses of Marker, Plot, and Shimmer; after the 65th batch added ShimmerText, an independent implementation of text scanning was established; after the 153rd batch added a StatusMarker, an independent implementation of the message status line was established; after the 154th batch added the ui/plot public drawing basic components, an independent implementation of Plot was also established.
2. There are still substantial gaps between data and input components: Chart has been supplemented with radar/Sankey chart, axis layout, four-way column chart and hover transition, and the 170th batch has been supplemented with fixed total points and multi-stop gradient mapping; DatePicker has been supplemented with date and time linkage, time preset and range time access; Input has been supplemented with masks, and Input/Textarea has been supplemented with edit menus and rich paste hooks, and has been connected to atomic reference basic editing and Windows/Linux X11 Rich reading; the 186th batch has access to custom token content and full soft line wrapping; still lacks touch-screen menus and pure Wayland rich reading, and Windows/Linux reading is pending acceptance by real devices; the circular progress gap of Progress has been filled in the first batch.
3. Editor has completed editing tracking decoration collections, replaceable language rules and custom search sessions; decoration coordinates, cross-line outlines and text styles are still different, see the component entry for details. `OnComplete`/`OnHover`/`OnDefinition` are application interfaces, and the LSP client is still provided by the application; this round does not treat it as a confirmed upstream built-in capability gap.
4. TextView has been supplemented with rich text folding preview, streaming fade-in, interval highlighting/positioning, plug-in and code block expansion, and passed automatic verification; the native window is still pending acceptance. Complete TeX/CSS is the boundary of Keel and cannot be regarded as an existing function of GPUI without any basis.
5. Recent additions to the Dock, Theme, Status Bar, and Kbd continue to retain completion records. When the Dock is separated and the window is opened by the application, the separated window will not be reopened when the layout is restored; the theme mechanism is already available, but the preset number and token format are still different.
6. The old table exaggerates the Badge icon/size, DescriptionList responsive column number, Kbd size, Switch size/loading, Toggle size, and Textarea maximum row count; all are corrected according to the current interface.
