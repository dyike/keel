# internal/oksvg

English | [简体中文](README.zh-CN.md)

Keel's internal copy of oksvg, used by ui/kit for SVG icons and images. Depends on rasterx and x/image, with no other Keel dependencies. UTF-8 is supported by default; `-tags keel_legacy_svg` adds upstream legacy charset decoding through x/net and x/text. See [attribution and patches](../../third_party/README.md#svg-parser).
